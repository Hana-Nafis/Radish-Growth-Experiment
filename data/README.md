# Dataset Information

This project uses the `CW1.RData` dataset, supplied for the MA52121 coursework at the University of Bath.

The dataset contains 18 observations and three variables:

- `soil` – soil type used (`clay`, `peat` or `sandy`).
- `fertiliser` – whether fertiliser was used (`yes` or `no`).
- `weight` – radish weight in grams after four weeks.

## Data Availability

The original `CW1.RData` file is not included in this repository because it was supplied for academic coursework and is not publicly available.

An authorised copy of `CW1.RData` is required to run the analysis.

## Usage

Place the authorised `CW1.RData` file in the working directory before running `radish_growth_analysis.R`.

The script loads the dataset using:

```r
load("CW1.RData")
```
